# API Testing

This section demonstrates my understanding of API testing and validation using tools such as Postman.

## API Testing Areas

- REST API Testing
- GET, POST, PUT and DELETE requests
- Request and Response Validation
- HTTP Status Code Validation
- Headers Validation
- JSON Response Validation
- Authentication Testing
- Positive Testing
- Negative Testing
- Boundary Testing
- Error Handling
- API Integration Testing

## API Validation Approach

The API testing process includes:

1. Understanding API requirements and documentation
2. Preparing API test scenarios
3. Creating requests with required parameters
4. Validating HTTP status codes
5. Validating response body and JSON fields
6. Validating headers
7. Performing positive and negative testing
8. Verifying error handling
9. Executing regression testing
10. Documenting defects and test results

## Example Validations

### Status Code

Verify that the API returns the expected HTTP status code.

### Response Body

Validate:

- Required fields
- Field values
- Data types
- Response structure

### Negative Testing

Validate API behaviour for:

- Invalid parameters
- Missing mandatory fields
- Invalid authentication
- Invalid resource IDs
- Unsupported requests

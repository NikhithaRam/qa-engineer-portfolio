# Python Test Automation

This section demonstrates my exposure to Python-based test automation using Pytest.

## Automation Stack

- Python
- Pytest
- Requests
- Postman
- PyCharm

## Automation Areas

- API Test Automation
- Request and Response Validation
- Status Code Validation
- JSON Response Validation
- Positive Testing
- Negative Testing
- Regression Test Automation
- Assertions
- Test Execution

## Automation Approach

The automation workflow includes:

1. Identify repeatable test scenarios
2. Create reusable test functions
3. Send API requests
4. Validate responses
5. Add assertions
6. Execute tests using Pytest
7. Analyze test results
8. Investigate failures
